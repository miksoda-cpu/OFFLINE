# Mitgelieferte Programme

Hier legt der Build-Workflow `kiwix-serve` je Zielsystem ab (`kiwix-serve-<target-triple>[.exe]`), siehe `.github/workflows/desktop.yml`. Für einen lokalen Build: `kiwix-tools` von https://download.kiwix.org/release/kiwix-tools/ laden und `kiwix-serve` hier mit dem passenden Suffix ablegen, z. B. `kiwix-serve-aarch64-apple-darwin`.
